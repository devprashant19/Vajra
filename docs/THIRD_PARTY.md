# Third-Party Dependencies

All dependencies are open-source and compatible with the project's licensing terms.

- **FastAPI** (MIT): Web framework.
- **lxml** (BSD): XML processing for CAP validation.
- **Next.js** (MIT): React framework for the frontend.
- **MapLibre GL JS** (BSD-3-Clause): WebGL map rendering.
- **deck.gl** (MIT): High-performance data visualization.
- **Open-Meteo** (CC-BY 4.0): Demo real data sample usage.
- **NASA IMERG** (Open Data): Precipitation data sample usage.
