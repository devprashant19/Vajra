# Fallback Plan

In the event of a live demo failure (e.g., network outage or container crash):
1. **Static Hosted Build**: We will switch to the Next.js static export hosted locally or on Vercel, which reads pre-generated demo bundles.
2. **Recorded Video**: A full 5-minute screencast of the `just demo` flow is available on the presenter's local machine as a final backup.
