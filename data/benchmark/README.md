# Benchmark Data

**Created**: 2026-10-02

## Origin
IMD 25-year (1901-2024 available, 2000-2024 used) Gridded Rainfall Data (0.25 x 0.25 degrees) from IMD Pune.
Copernicus DEM (GLO-30 / GLO-90) from ESA via earthaccess.

## Contents
Contains `events_benchmark.csv` (gold standard benchmark events), `controls.csv` (control days without severe rain), and `events_auto.csv` (candidate rows).
Verdict: High quality proxy data for benchmarking.

## Usage Restrictions
IMD Gridded Rainfall: Non-commercial research use only, strict attribution required (UNVERIFIED).
Copernicus DEM: Free and open access with attribution.
